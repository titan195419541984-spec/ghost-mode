# Ghost Studio — current release

Ghost Studio creates a structured content-writing package from a user-entered topic or a selected Ghost Mode trend.

## Included
- Topic input and platform, format, creative direction, and duration controls.
- Topic-aware hook, script/voiceover transcript, five-part scene plan, platform-specific caption, and topic/category-aware hashtags.
- Scene durations that sum to the selected target length.
- Copy actions for the complete package, script, and caption/hashtags.
- Downloadable plain-text production package with an editorial verification checklist.
- Browser-local generation; no provider API key or paid generation service is required.

## Not included in this release
- AI footage, image generation, synthesized voice, music or sound effects.
- MP4 or WebM video rendering/export.
- User accounts, cloud project storage, scheduled publishing, or platform posting.
- A hosted language model. The writing engine uses structured templates and topic-aware composition; it is not a substitute for editorial review.

## Publishing standard
Treat generated copy as a draft. Verify source material, names, dates, statistics, quotations, and claims before publishing. Ghost Mode does not promise views, reach, or virality.
