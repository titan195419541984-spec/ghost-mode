# Ghost Studio

Included: trend/topic brief input, platform/format/tone/duration controls, hook/script/scene plan/caption/hashtags/transcript, script download, publish-pack copy, and client-side 720x1280 animated WebM export.

Limitations: video output is animated typography, not photorealistic AI footage; WebM rather than MP4; silent; the script planner is a local structured generator, not a hosted LLM. Real image/video generation and voice synthesis require a configured media provider, storage, usage controls, and user authentication.
